# Checklist de entrega AP4

1. Importar SIGITEC_TP4_Integrador como proyecto Maven en Eclipse y ejecutar `Main` en modo demostración.
2. Ejecutar la clase `PruebasIntegradorasTP4` y tomar captura de 15/15.
3. Ejecutar con `--mysql` en el mismo servidor MySQL del TP3; comprobar consulta, registrar un ticket, cambiar de estado, consultar historial (opción 12), reiniciar y revisar persistencia.
4. Probar opción 10 (resumen), 11 (CSV), revisar el archivo `reportes/incidencias_tp4.csv`.
5. Subir al mismo repositorio GitHub los archivos `src`, `database`, `docs`, `pom.xml`, `README.md`, `.gitignore`. No subir `bin`, `target`, `.settings`, reportes locales ni contraseñas. Si el repositorio tiene `README_AP2.md` y `diagrams` conservarlos.
6. Grabar video de aproximadamente 3 minutos con `docs/guion_video_tp4.md`. Mostrar pantalla real y narrar con tus palabras.
7. Verificar que el commit TP4 ya esté en `https://github.com/ozfuentealba/Sigitec` y que el enlace abra el código nuevo. Actualizar el PDF si fuera necesario con fecha/link de video.
8. Entregar en la plataforma `FUENTEALBA-OSCAR-AP4.pdf` más el video o el enlace, según lo permita la actividad.

**Advertencia de evaluación:** el informe y el prototipo contienen pruebas automáticas realmente ejecutadas, y evidencias de JDBC del TP3. No se afirma que las funciones nuevas de TP4 ya se validaron en la PC del alumno; requieren los pasos 2-4.
